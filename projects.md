# Projects

## Dynamic Credit System (Geo-Aware Credit Intelligence)
Status: In Progress
Description: Rule-based dynamic credit limit engine using real-time location context and behavioral risk signals including spend velocity and utilization patterns. Implemented geo-fencing with OpenStreetMap POIs for high-risk zone detection and triggered credit limit updates on geo-fence entry events. Designed ML-ready architecture for future model-driven credit optimization and A/B testing framework.
Tech: Python, OpenStreetMap, Geo-fencing, Risk Modeling, A/B Testing, ML Architecture

## Portable AI: USB-Based Local LLM System

Tech: llama.cpp, GGUF Quantization, SillyTavern, LLM Inference, OpenAI-compatible API, Context Management
